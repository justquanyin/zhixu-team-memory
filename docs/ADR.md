# 架构决策记录

日期：2026-10-31。以下均描述本次源码的实际选择。

## ADR-001：三实体，不让 Session Summary 自动成为团队事实

**决策**：Session、Candidate、TeamKnowledge 独立表与生命周期；原始证据、快照、审计由触发器保护；只有明确审核才晋升。

**理由**：会话包含建议、否决、失败尝试和未验证断言，摘要无法替代事实确认。借鉴 ReMe 分层与 Memorix curated memory 的思想，自研团队审核语义。

**代价**：增加人工审核成本。MVP 不实现模型自动审批、跨候选自动合并。

## ADR-002：同一 PostgreSQL SQL，PGlite 负责零 Docker 演示

**决策**：持久化 PGlite 是默认后端；外部 PostgreSQL 使用 pg 连接池。两者加载同一 pgvector 迁移和业务 SQL。

**理由**：用户要求可运行垂直切片，当前 Docker daemon 不可用；真实 PostgreSQL 引擎比内存数组/mock 更能验证 SQL 与事务。

**代价**：PGlite 单进程使用，不支持多个服务实例共享同一目录。外部 PostgreSQL 的启动配置已提供，但本环境未实测。切换后不自动迁移已有数据。

## ADR-003：用库能力复用，团队治理独立实现

**决策**：直接复用 React、Express、Zod、pg/PGlite、pgvector、官方 MCP SDK。Motif/Memorix/ReMe/Graphiti/LangMem 只做架构参考，未复制源码、未运行其服务。

**理由**：本 MVP 的核心需求是三实体、证据、权限、审核和中文运营闭环；引入 Python 图谱框架、额外图数据库或完整已有产品，会扩大运行依赖并增加接入成本。

**代价**：没有直接得到成熟的长期记忆整合、语义冲突分析、图遍历与 agent hooks。详见许可证清单。

## ADR-004：离线可运行，模型集成是显式 opt-in

**决策**：默认规则提取，提供真实可调用的 OpenAI-compatible JSON 提取器；默认词法 hashing 向量，不使用外部 embedding 服务。

**理由**：没有用户密钥，不虚构外部模型已接通。也避免默认把团队会话发送到外部。

**代价**：规则会漏提取/误提取，同义改写召回效果弱。模型提取只经过模拟协议测试。生产应引入 provider 适配、模型版本管理、真实评测、重试和队列。

## ADR-005：稳定主题键定义 MVP 冲突边界

**决策**：冲突要求项目/可见范围/topic_key 一致；不同文本必须明确替代，相同文本也需要处理重复。人工可修改候选主题键。

**理由**：可解释、可测试，避免声称模型已经可靠理解所有自然语言矛盾。

**代价**：不同 key 下的语义冲突不会自动发现；自动生成的哈希 key 更保守，需要审核员归并主题。

## ADR-006：当前状态投影 + 不可变版本快照

**决策**：知识正文编辑递增 version 并保存快照；另一条候选替代时创建新 ID + superseded_by。版本编辑要求提交当前 version，避免静默覆盖并发修改。

**理由**：同时支持当前召回、修订审计与旧决策解释。借鉴 Graphiti 的时间有效性/事实替代思路，但未实现时序知识图谱。

**代价**：两类更新语义需分别展示；当前无任意历史时间点全库查询和回滚按钮。旧内容可通过候选重新走审核。

## ADR-007：服务端过滤先于检索排序

**决策**：项目角色 + team/private 范围在 API 和检索 SQL 中落实；管理员不绕过私有范围，日志也按调用者私有保存。

**理由**：不允许先从全库检索后由前端剔除，否则候选、分数或日志都可能泄露权限外数据。

**代价**：当前不是数据库 RLS；直接 DB 访问必须限制。团队汇总指标尚未实现，只展示个人最近 200 次请求。

## ADR-008：MCP 复用 API 身份体系

**决策**：官方 SDK stdio server，通过个人 Bearer token 调用相同 HTTP API；不直接访问 DB；只暴露查询与反馈工具。

**理由**：统一权限与日志，避免形成独立的不受控检索入口；真实 SDK 客户端纳入测试。

**代价**：MCP 子进程依赖已启动的本地应用；未提供 Streamable HTTP、OAuth 或远程托管 MCP。

## ADR-009：证据先提交，提取失败可重试

**决策**：Session 归档独立提交，模型/规则提取在之后运行；失败记入 extraction_runs，不回滚已归档证据。

**理由**：网络失败不能导致原始 Session 丢失。候选按 Session + topic_key 幂等。

**代价**：当前同步提取存在长请求，进程中断可能只留下证据而未产生运行记录。UI 可重新提取；正式队列和恢复扫描属于下一阶段。
